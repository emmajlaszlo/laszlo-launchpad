# Laszlo Launchpad

Your personal local web app for tracking medtech UX research, human factors, and product roles in California (SF Bay, San Diego, LA), aimed at a **summer / fall 2027** start.

## Your link

```bash
npm install
npm run dev
```

Open **http://localhost:5173** and bookmark it.

Data is stored in your browser (`localStorage`). Use **Export** anytime for a JSON backup.

## What’s inside

- **Home** — countdown to target start, hunt signals, priority companies, milestones
- **Companies** — 20 starter medtech/healthtech orgs with careers links, stages, priorities
- **Jobs** — log openings as you find them
- **Pipeline** — watching → networking → applied → offer
- **Profile** — tailor cities, roles, and target date

## Stack

Vite + React + TypeScript. No backend required.
